# 《不可打扰》精读卡片：批次2

范围：主书 PDF p.101–192，第13–25章。

ID：BKDR-13-01  
类型：审计框架  
名称：外部触因服务性检验  
一句话定义：逐项问“它在为我服务，还是我在为它服务”。  
论证链：通知/设备打断 → 注意切换成本 → 与既定意图比较 → 保留有益触因、删除无益触因  
证据：研究与案例混合；邮件、手机在场和工作中断研究多为实验/观察，样本细节常未完整呈现；A/B/D。  
适用边界：个人学习和课堂环境。  
失效条件：紧急通知、医疗照护或安全联络需要例外。  
与目标锚点的关系：直接可用。  
可操作化：课程通知默认关闭，仅在学生选择的时间窗口发送；不把提醒频率当作参与度指标。  
出处：[不可打扰·章13–14 / PDF p.101–140]

ID：BKDR-15-01  
类型：方法工具  
名称：T=n×t邮件模型  
一句话定义：邮件总耗时等于数量乘以单封处理时间。  
论证链：邮件数量增加或反复查看 → 总时间和切换成本上升 → 分批处理、减少发送 → 恢复连续注意  
证据：作者引用职场研究，称查看后平均需64秒调整；样本与设计书中未涉及；强度B/D。  
适用边界：成人异步沟通。  
失效条件：把儿童家长沟通完全改成异步消息，导致紧急事项延误。  
与目标锚点的关系：需改造。  
可操作化：家长沟通设固定窗口，紧急事项走单独渠道；不要求孩子即时回复。  
出处：[不可打扰·章15 / PDF p.143–162]

ID：BKDR-16-01  
类型：方法工具  
名称：群聊时间盒与成员最小化  
一句话定义：群聊应限时、限人、限主题。  
论证链：持续群聊产生外部触因 → 实时切换和焦虑增加 → 设定窗口并减少成员 → 沟通更聚焦  
证据：Basecamp经验和作者建议，强度D/E。  
适用边界：项目协作。  
失效条件：将群聊用作儿童社交评价或公开排名。  
与目标锚点的关系：直接可用。  
可操作化：AI项目群只保留必要成员，关闭非任务通知，规定退出无惩罚。  
出处：[不可打扰·章16 / PDF p.163–177]

ID：BKDR-17-01  
类型：方法工具  
名称：会议前置议程与设备隔离  
一句话定义：先书面准备，再开短会；非必要设备离场。  
论证链：无议程会议 → 注意分散和低效 → 提前提交问题/方案 → 会议用于共识而非漫谈  
证据：研究与作者主持经验，具体样本未涉及；强度D/E。  
适用边界：教师、家长和学生项目协作。  
失效条件：需要无障碍设备、实时记录或紧急联络时。  
与目标锚点的关系：需改造。  
可操作化：学生展示时只保留一台演示设备，手机集中存放；会后提供书面摘要。  
出处：[不可打扰·章17 / PDF p.178–192]

ID：BKDR-18-01  
类型：方法工具  
名称：手机应用四步减扰  
一句话定义：卸载、整理、重设通知、启用勿扰。  
论证链：应用过多/通知泛滥 → 外部触因增加 → 删除非必要应用并分层通知 → 手机回到工具角色  
证据：作者实践；称2013年苹果发送7.4万亿条推送、不到15%用户修改通知，来源细节和独立核验未在本批完成；强度E。  
适用边界：成人和家庭设备管理。  
失效条件：把孩子设备完全交给监控软件或阻断求助。  
与目标锚点的关系：直接可用。  
可操作化：儿童设备默认低通知、夜间勿扰、家长可见设置；保留紧急联系人白名单。  
出处：[不可打扰·章18 / PDF p.193–224]

ID：BKDR-22-01  
类型：框架模型  
名称：预先承诺  
一句话定义：在冲动出现前改变未来选择的条件。  
论证链：预见高风险触因 → 事先设置限制/成本 → 冲动时减少可选路径 → 更可能遵守目标  
证据：尤利西斯协议和行为研究概括；具体实验细节待核查；强度D/E。  
适用边界：自愿、可撤回、低风险的注意力管理。  
失效条件：成人替儿童签订不可退出协议，或协议阻断求助和必要使用。  
与目标锚点的关系：直接可用。  
可操作化：学生与家长共同设置设备窗口和休息时段；允许修改，不以失败羞辱。  
出处：[不可打扰·章22 / PDF p.225–246]

ID：BKDR-23-01  
类型：方法工具  
名称：努力协议  
一句话定义：让不必要行为多一步操作，降低冲动发生率。  
论证链：增加访问摩擦 → 冲动需重新确认 → 获得反思间隔 → 选择继续或回到任务  
证据：Forest、SelfControl、Focusmate案例；无统一对照实验，强度D/E。  
适用边界：短时专注任务。  
失效条件：长期学习、紧急访问或儿童需要即时求助。  
与目标锚点的关系：直接可用。  
可操作化：编程专注时段屏蔽娱乐通知，保留求助和无障碍通道；不使用强制锁机。  
出处：[不可打扰·章23 / PDF p.1476–1587]

ID：BKDR-24-01  
类型：证据与边界  
名称：代价协议不宜普遍儿童化  
一句话定义：金钱赌注可能提高短期坚持，但有明显副作用。  
论证链：分心附加损失 → 短期动机提高 → 行为完成率可能上升；但自责、焦虑和失败成本也上升  
证据：《新英格兰医学杂志》戒烟研究：教育组6%、奖励组17%、押金组52%成功戒烟；参与者自愿加入，约48%押金组未成功；成人戒烟样本，A级但不可直接迁移儿童。  
适用边界：自愿成人短期目标。  
失效条件：未成年人、家庭经济差异、容易自责或长期学习。  
与目标锚点的关系：禁用清单。  
可操作化：不用扣钱、公开惩罚或失去课程资格来换取专注；改用可恢复的时间和任务边界。  
出处：[不可打扰·章24 / PDF p.1593–1778]

ID：BKDR-25-01  
类型：框架模型  
名称：身份协议  
一句话定义：用“我是专注的人”重塑对行为的自我解释。  
论证链：身份表述改变 → 选择与自我形象保持一致 → 更可能执行预先承诺  
证据：2011年斯坦福投票措辞实验；样本和效应量本批未完整呈现；实验性证据，等级未定。  
适用边界：支持性、自主选择的自我叙事。  
失效条件：把失败归因于“你不是专注的人”，造成羞耻和标签化。  
与目标锚点的关系：需改造。  
可操作化：使用“我正在练习专注”而非固定人格标签；允许复盘和重新开始。  
出处：[不可打扰·章25 / PDF p.1779–192]

## 本批反向提醒

1. 外部触因管理应服务儿童目标，不应变成全天候监控。[推论]
2. 代价协议的成人戒烟效果不能迁移到儿童学习，且不应制造经济惩罚。[推论]
3. “身份协议”只能是可成长的自我叙事，不能成为失败标签。[推论]
