# 《上瘾》精读卡片：批次2

## 批次范围

PDF p.80–141：第4章“多变的酬赏”、第5章“投入”、第6章“上瘾模型与道德操控”。

ID：SY-4-01  
类型：因果机制  
名称：期待酬赏比酬赏本身更驱动行动  
一句话定义：行为动力主要来自等待奖励时的渴望与紧张。  
论证链：奖励结果不确定 → 期待产生渴望 → 注意力集中并重复行动 → 获得或继续寻找奖励  
证据：奥尔兹与米尔纳20世纪40年代动物电刺激实验；后续人类实验的研究者、样本和年份书中未涉及；斯坦福布莱恩·克努森团队的功能磁共振赌博研究，样本和年份书中未涉及；实验性证据，强度未定。  
适用边界：解释赌博、信息流、游戏等期待型体验。  
失效条件：奖励明确、一次性完成，或学习目标依赖延迟满足和深度加工。  
与目标锚点的关系：直接相关，作为风险识别而非设计建议。  
可操作化：学习反馈应解释“为什么对/错”和下一步，而非隐藏结果或制造悬念；不使用随机奖励刺激重复点击。  
出处：[上瘾·章4 / PDF p.80–83]

ID：SY-4-02  
类型：证据  
名称：间隔性强化增加反应频率  
一句话定义：奖励并非每次出现时，动物反而更频繁按压。  
论证链：行为与奖励存在关联但结果不确定 → 期待持续 → 行为次数增加  
证据：斯金纳20世纪50年代鸽子操纵杆实验；鸽子数量、实验具体年份和程序细节书中未涉及；动物实验，不能直接推及儿童学习，强度未定。  
适用边界：说明不确定反馈为何可能强化重复行为。  
失效条件：需要稳定规则、公平评价和可预测练习结果的教育情境。  
与目标锚点的关系：直接可用作禁用机制识别。  
可操作化：不把抽奖、随机徽章、随机积分作为作业反馈；若有探索性活动，明确其娱乐属性及退出方式。  
出处：[上瘾·章4 / PDF p.82–84]

ID：SY-4-03  
类型：概念  
名称：三类多变酬赏  
一句话定义：社交、猎物和自我酬赏满足不同心理需要。  
论证链：用户需要认同/资源/胜任感 → 产品提供相应反馈 → 需求暂时满足并产生继续期待  
证据：作者对产品与心理学文献的归纳；统一样本与效应量书中未涉及；强度 E。  
适用边界：用于拆解反馈满足的是哪类需求。  
失效条件：把点赞、资源掉落或升级本身当作学习价值。  
与目标锚点的关系：直接可用，但社交酬赏对未成年人应提高保护标准。  
可操作化：优先使用具体、可解释的能力反馈；同伴展示须自愿、可关闭，不公开排名或制造比较焦虑。  
出处：[上瘾·章4 / PDF p.83–84, 107–110]

ID：SY-4-04  
类型：反直觉结论  
名称：酬赏必须满足真实需求且保持适度新意  
一句话定义：单纯增加奖励不能长期维持兴趣。  
论证链：奖励与用户真实需求脱节 → 短期新奇耗尽 → 用户热情下降；重复包装无法替代真实价值  
证据：Quora与Zynga案例；Zynga 2009年“农场小镇”每月8380万活跃用户、2010年收入3600万美元、2012年11月股价下跌80%；商业案例，样本与因果识别未提供，强度 D/E。  
适用边界：产品迭代和反馈设计的假设检验。  
失效条件：把商业热度变化直接解释为单一机制导致。  
与目标锚点的关系：直接可用。  
可操作化：每种奖励必须映射到具体技能或学习需求；不以“换皮主题”和持续新奇掩盖练习质量。  
出处：[上瘾·章4 / PDF p.103–108, 116–127]

ID：SY-5-01  
类型：心理机制  
名称：投入增加与宜家效应  
一句话定义：人们往往高估自己投入劳动后产物的价值。  
论证链：亲自投入劳动 → 产生所有感与合理化 → 对产物评价提高 → 更愿继续使用  
证据：阿雷利、诺顿和莫孔2011年折纸竞价实验；对象为美国大学生，分为自己折纸、普通观察者和折纸能手作品评价组；作者称自己动手者估值约为观察者5倍，具体样本量书中未涉及；实验性证据，强度未定。  
适用边界：作品确实由学习者完成，且评价不替代客观质量标准。  
失效条件：投入被用来锁定用户、掩盖低质量或制造沉没成本。  
与目标锚点的关系：直接可用。  
可操作化：让孩子保存、解释和迭代自己的代码；同时允许导出、重做和放弃，不把“投入过”变成必须续费的理由。  
出处：[上瘾·章5 / PDF p.112–113]

ID：SY-5-02  
类型：证据  
名称：小承诺提高后续顺从  
一句话定义：先完成小行动可能提高随后接受更大要求的概率。  
论证链：先做小承诺 → 形成与过去行为一致的自我形象 → 更可能接受大承诺  
证据：居民标语实验；先贴3英寸“平安行车”小标语组，后续接受院前大标牌比例76%，对照组17%；研究名称、年份、样本规模书中未涉及；现场实验，强度未定。  
适用边界：解释承诺一致性，不应用于绕过知情同意。  
失效条件：后续要求涉及付费、隐私、持续使用或儿童无法理解的长期后果。  
与目标锚点的关系：需改造，默认高风险。  
可操作化：课堂允许随时撤回项目承诺；小练习不得自动转为购买、公开展示或长期订阅。  
出处：[上瘾·章5 / PDF p.114–115]

ID：SY-5-03  
类型：框架模型  
名称：投入的三类储存价值  
一句话定义：内容、数据和关系投入会提高后续服务价值与回访概率。  
论证链：用户添加作品/资料/关系 → 系统个性化或累积价值增加 → 放弃和迁移成本上升 → 更可能返回  
证据：iTunes、LinkedIn、Mint、Twitter、Pinterest等产品案例；Any.do移动应用研究称2010年下载应用中26%仅使用一次，研究来源和样本细节正文未涉及；强度 D/E。  
适用边界：用户拥有数据、可理解用途且能自由迁移时。  
失效条件：数据不可导出、关系被平台垄断、儿童不理解隐私后果。  
与目标锚点的关系：直接可用作产品审计。  
可操作化：代码、作品、反馈记录一键导出；最小化收集个人数据，不以连接日历、通讯录或社交账户作为学习前提。  
出处：[上瘾·章5 / PDF p.116–127]

ID：SY-5-04  
类型：因果机制  
名称：先酬赏、后投入  
一句话定义：投入要求应发生在用户获得价值之后，并逐步增加。  
论证链：先获得有意义反馈 → 感知服务有价值 → 愿意做小投入 → 投入加载下一触发  
证据：斯坦福电脑互惠实验；两组获得帮助程度不同，得到有益帮助组后续回馈“几乎是原来的两倍”；样本、年份和随机化方法书中未涉及；实验性证据，强度未定。  
适用边界：自愿、低风险、可撤回的学习投入。  
失效条件：先收集隐私、先要求绑定账户，或用投入换取基本功能。  
与目标锚点的关系：直接可用。  
可操作化：先让学生完成一次真正有反馈的创作，再邀请保存偏好；绑定家长联系方式、公开作品等必须单独同意。  
出处：[上瘾·章5 / PDF p.116–117]

ID：SY-6-01  
类型：伦理框架  
名称：操控模式四象限  
一句话定义：用“我会用吗”和“能否改善生活”判断设计责任。  
论证链：设计者自用与否 × 相信产品是否提升生活质量 → 健康习惯推广者/兜售商/娱乐用户者/经销商 → 责任和风险不同  
证据：作者提出的决策支持工具与规范性论证；不是效果研究；强度 E。  
适用边界：作为发布前伦理筛查起点。  
失效条件：设计者与儿童用户存在权力差、产品影响不可逆，或“我会用”掩盖商业利益。  
与目标锚点的关系：直接可用，但必须比原书标准更严格。  
可操作化：增加三项儿童审查：使用者是否知道机制、是否能无惩罚退出、是否达成其自己认可的学习目标；任一答不上来即禁用。  
出处：[上瘾·章6 / PDF p.133–141]

ID：SY-6-02  
类型：争议点  
名称：责任归属的摇摆  
一句话定义：作者同时主张企业保护成瘾用户，也把最终责任较多交给用户。  
论证链：产品可能造成过度使用 → 少数用户出现病理性问题 → 企业应识别保护；但多数用户被要求自行规范 → 设计者责任边界不稳定  
证据：作者称老虎机病理性上瘾用户约1%，但来源、样本和定义在本批正文未充分说明；规范性论证，强度未定。  
适用边界：成人产品责任讨论。  
失效条件：未成年人、不可退出设计、平台掌握行为数据且用户缺乏谈判能力。  
与目标锚点的关系：直接相关，必须反对其“多数责任在用户”的成人假设。  
可操作化：平台侧承担默认保护责任：限频、夜间关闭、家长可见、数据最小化和独立退出。  
出处：[上瘾·章6 / PDF p.137–140]

## 本批反向提醒

1. 不确定反馈可能增加重复行为，但学习需要可预测、可解释和公平的反馈。[推论]
2. 小承诺和储存价值能提高留存，也可能制造沉没成本和退出障碍。[推论]
3. “设计者自己会用”不足以证明儿童用户获益；成人需求和儿童最佳利益不是同一件事。[推论]
4. 《上瘾》把约1%的病理性上瘾比例写成行业估计，不能当作适用于AI课程儿童的风险概率。[推论]
