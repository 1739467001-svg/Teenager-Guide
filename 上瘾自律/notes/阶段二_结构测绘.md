## 一、《上瘾》论点树

### 全书主命题

[原文] 习惯型产品通过“触发—行动—多变酬赏—投入”的循环，使用户反复使用，并逐步形成内部触发。[上瘾·前言、章1–5 / PDF p.10–132]

### 一级论点

1. [原文] **习惯具有商业价值**：高频使用降低营销依赖、提高用户终身价值，并形成竞争壁垒。机制是重复使用逐渐把产品与特定情绪或情境绑定。主要证据为企业案例、作者观察和行为心理学解释，以 D/E 为主。[上瘾·章1 / PDF p.20–34]
2. [原文] **触发启动行为**：外部触发先提示行动，重复循环后，情绪和情境成为内部触发。主要证据为产品案例与心理学理论，C/D/E 混合。[上瘾·章2 / PDF p.35–49]
3. [原文] **行为发生取决于动机、能力与触发同时存在**：降低操作难度通常比继续增强动机更可靠。主要证据为福格行为模型、启发式原则及案例，证据以理论模型和 D/E 为主。[上瘾·章3 / PDF p.50–79]
4. [原文] **多变酬赏维持期待**：社交、资源和自我成就三类酬赏通过不确定性提高反复行动的吸引力。主要证据为动物实验、心理学实验与产品案例，包含 A/D/E，但需在精读阶段逐项核查样本和年份。[上瘾·章4 / PDF p.80–110]
5. [原文] **投入提高下一轮使用概率**：用户投入内容、数据、关注关系、技能或声誉，会储存价值并加载新的触发。主要证据为产品案例和行为解释，以 D/E 为主。[上瘾·章5 / PDF p.111–132]
6. [原文] **操控工具需要伦理筛选**：作者以“设计者是否使用产品”和“产品是否实质改善用户生活”区分不同操控者，并主张通过实际用户行为持续测试模型。主要证据是规范性框架和案例，不属于因果证据。[上瘾·章6、章8 / PDF p.133–160]

### 隐含前提

- [推论] 可观察到的高频行为被默认能够代表用户真实获益，但使用频率也可能来自压力、依赖或退出成本。[上瘾·章1、章8 / PDF p.20–34, 151–160]
- [推论] 作者的伦理测试依赖设计者自我判断；设计者与 9–14 岁儿童在成熟度、权力和风险承受能力上并不对等。[上瘾·章6 / PDF p.133–141]
- [推论] 从成人消费产品案例平移到儿童教育，缺少年龄适配的独立论证。[上瘾·章1–8 / PDF p.20–160]

## 二、《不可打扰》论点树

### 全书主命题

[原文] 专注不是排斥技术，而是按价值和预先计划行动；管理分心需要依次处理内部触因、时间安排、外部触因和预先承诺。[不可打扰·章1–2、章节要点 / PDF p.18–32, 263–267]

### 一级论点

1. [原文] **分心的根源通常是不适感**：压抑欲望可能增强欲望，应识别、记录并重新解释内部触因。主要证据包括心理学研究、自我实验和案例，A/C/D/E 混合。[不可打扰·章3–8 / PDF p.33–70]
2. [原文] **价值必须被转化为时间安排**：时间盒把“打算做什么、什么时候做”显性化，是否按计划行动比单纯追求结果更能判断分心。主要证据为实施意图研究与案例，具体强度待精读核查。[不可打扰·章9–12 / PDF p.71–100]
3. [原文] **外部触因应逐项审计**：通知、邮件、群聊、会议、手机和新闻只有在服务既定意图时才有价值。主要证据以工作与个人案例、操作经验为主，D/E 居多。[不可打扰·章13–21 / PDF p.101–162]
4. [原文] **预先承诺增加分心成本**：努力协议、代价协议和身份协议把未来选择约束在目标范围内。证据包括实验、案例和作者实践，A/D/E 混合。[不可打扰·章22–25 / PDF p.163–192]
5. [原文] **持续分心也可能是制度问题**：永远在线、心理安全不足和无法公开讨论问题的文化，会把技术过度使用制度化。主要证据为组织案例和访谈，D 为主。[不可打扰·章26–28 / PDF p.193–217]
6. [原文] **儿童需要自主参与专注管理**：先满足自主性、控制感和归属感，再让孩子参与时间安排、清除触发因素并作出协议。主要证据为动机理论、家庭案例与作者经验，理论/C/D/E 混合。[不可打扰·章29–33 / PDF p.218–250]

### 隐含前提

- [推论] 模型假设个人对时间与环境拥有足够控制权；学校课程、家庭权力关系和平台设计可能限制这种控制。[不可打扰·章9–28 / PDF p.71–217]
- [推论] “内部不适驱动分心”解释力很强，但可能低估专门优化的成瘾设计、发展年龄和群体压力。[不可打扰·章3、章29–33 / PDF p.33–41, 218–250]
- [推论] 亲子协商默认成人能够稳定示范且尊重儿童意见，这在现实家庭中并不总成立。[不可打扰·章29–33 / PDF p.218–250]

## 三、《欲罢不能》论点树

### 全书主命题

[原文] 数字环境把目标、反馈、进步、挑战、未完成感和社会联系组合成难以抵挡的体验；防护需要重构环境和设计，而非只依赖意志力。[欲罢不能·楔子、章4–11、尾声 / PDF p.12–20, 75–218, 236–238]

### 一级论点

1. [原文] **行为上瘾不只发生在少数特殊人群**：环境与可获得性会使普通人出现强迫性使用。主要证据包括流行率综述、访谈、病例和历史材料，S/C/D/E 混合。[欲罢不能·章1–3 / PDF p.21–74]
2. [原文] **目标会变成没有停止点的追逐**：量化指标和不断更新的目标使“完成”迅速被下一个缺口取代。主要证据为案例、实验和观察，A/C/D/E 混合。[欲罢不能·章4 / PDF p.75–94]
3. [原文] **不可预测反馈、可见进步和升级挑战共同维持投入**：即时反馈降低等待成本，渐进难度让能力与挑战持续匹配。主要证据包含实验、游戏及产品案例，A/D/E 混合。[欲罢不能·章5–7 / PDF p.95–144]
4. [原文] **未完成感和社会评价延长心理占用**：悬念、无限内容、点赞和比较让体验难以自然结束。主要证据包括经典实验、平台案例和访谈，A/C/D/E 混合。[欲罢不能·章8–9 / PDF p.145–178]
5. [原文] **儿童防护应强调现实交流、渐进接触和成人边界**；对已形成的问题，环境调整和认知行为方法比单靠禁绝更可行。主要证据包括儿童研究、治疗案例和访谈，A/C/D 混合。[欲罢不能·章10–11 / PDF p.179–218]
6. [原文] **游戏化既可服务健康与学习，也可用于牟利和操控**；作者主张为产品设置暂停点、减少数字指标、保留无屏幕时空。主要证据为应用案例和规范性判断，D/E 为主。[欲罢不能·章12、尾声 / PDF p.219–238]

### 隐含前提

- [推论] 作者把多种行为放在“上瘾”连续谱上，但不同章节使用的诊断标准和危害阈值可能并不完全一致。[欲罢不能·章1–3 / PDF p.21–74]
- [推论] 从平台、赌博和游戏机制推及普通教学反馈，需要区分“高投入”“习惯”和“功能受损的上瘾”。[欲罢不能·章4–9 / PDF p.75–178]
- [推论] 设计者愿意设置停止点的前提，与依赖使用时长或留存率的商业模式存在直接冲突。[欲罢不能·尾声 / PDF p.236–238]

## 四、《焦虑的一代》论点树

### 全书主命题

[原文] 2010–2015 年间从玩耍式童年转向手机式童年，是青少年心理健康恶化的重要原因；逆转需要家庭、学校、科技公司和政府集体行动。[焦虑的一代·前言、章1、章9–12、结语 / PDF p.12–32, 34–66, 253–326, 327–332]

### 一级论点

1. [原文] **Z 世代心理健康指标出现同步恶化**：作者以跨年份、跨国家趋势和替代解释排除来支持时间上的转折。证据包括时间序列、横断面调查、纵向资料与综述，S/B/C 混合；因果力度必须在阶段三逐项审查。[焦虑的一代·章1 / PDF p.34–66]
2. [原文] **儿童发展依赖现实交往、自由玩耍、冒险和渐进独立**：这些经验支持社会学习、反脆弱性和执行功能发展。证据包含发展心理学研究、观察与历史比较，S/A/B/C/D 混合。[焦虑的一代·章2–4 / PDF p.67–137]
3. [原文] **手机式童年造成四类核心伤害**：社会剥夺、睡眠剥夺、注意力碎片化和成瘾，通过时间替代、夜间使用、持续中断和强化机制影响发展。证据包含实验、纵向研究、横断面研究及平台案例，A/B/C/D 混合。[焦虑的一代·章5 / PDF p.138–169]
4. [原文] **影响存在性别差异**：女孩更易受社会比较、关系攻击和情绪传播影响；男孩更多从现实世界撤退到游戏、色情和线上娱乐。证据包含趋势数据、队列、相关研究和案例，B/C/D 混合。[焦虑的一代·章6–7 / PDF p.170–232]
5. [原文] **问题也具有精神与价值层面**：手机式生活削弱共同注意、具身关系、自我超越和意义感。主要依据宗教哲学传统、解释性材料和案例，D/E 与规范论证为主。[焦虑的一代·章8 / PDF p.233–251]
6. [原文] **个体家庭无法独自解决集体行动困境**：作者提出推迟智能手机和社交媒体、校园无手机、增加无监督玩耍等协调方案。证据包含政策案例、学校实践和规范性推理，D/E 为主，政策效果仍需验证。[焦虑的一代·章9–12 / PDF p.253–326]

### 隐含前提

- [推论] 多国趋势同步与时间吻合被用作因果链的重要支柱，但共同时间趋势仍不能单独证明智能手机是主因。[焦虑的一代·章1 / PDF p.34–66]
- [推论] “玩耍式童年”被设为较优基线，但其安全性和可行性依赖社区、文化、性别及家庭资源。[焦虑的一代·章2–4 / PDF p.67–137]
- [推论] 美国及其他西方国家的证据被部分推广到中国儿童，跨文化等效性仍需单独验证。[焦虑的一代·中文版序、章1 / PDF p.8–11, 34–66]
- [推论] 集体限制可能减少伤害，但也可能影响数字技能培养、残障儿童支持或边缘群体的线上联结，书中结构未把这些收益放在同等位置衡量。[焦虑的一代·章5–12 / PDF p.138–326]

## 五、阶段性对撞线索（仅作阶段三待验证问题）

1. 《上瘾》把降低摩擦、可变酬赏和投入视为习惯形成工具；《欲罢不能》将高度相似的结构列为行为上瘾风险。两者差异可能不在机制，而在目标、停止点、透明度与功能损害。[推论｜上瘾·章3–5；欲罢不能·章4–9]
2. 《不可打扰》强调个人和家庭掌控，《焦虑的一代》强调集体行动与制度责任。两者可能分别适用于个体层和环境层，不能简单互相否定。[推论｜不可打扰·章22–33；焦虑的一代·章9–12]
3. 三本成人导向书中的方法不能默认适用于 9–14 岁儿童；阶段三必须为每张应用卡补查原始样本年龄。[推论｜上瘾、不可打扰、欲罢不能]
4. “游戏化学习”是高相关、高风险交叉点：需要区分促进掌握的反馈与制造无停止点的留存设计。[推论｜上瘾·章3–5；欲罢不能·章12]
