# 《不可打扰》精读卡片：批次1

范围：主书 PDF p.18–100，第1–12章。

ID：BKDR-1-01  
类型：框架模型  
名称：专注力管理四步法  
一句话定义：先处理内部触因，再安排时间、清理外部触因并预先承诺。  
论证链：识别不适 → 为重要价值预留时间 → 审计通知与环境 → 用协议约束未来选择  
证据：作者综合行为科学、案例与个人实践；统一验证研究未给出，强度D/E。  
适用边界：个人和家庭的日常注意力管理。  
失效条件：学校制度、平台设计或家庭权力超出个人控制时。  
与目标锚点的关系：直接可用。  
可操作化：AI课按四步审查每个功能；默认关闭非必要通知，明确学习时间和退出路径。  
出处：[不可打扰·章1–2 / PDF p.18–32]

ID：BKDR-3-01  
类型：因果机制  
名称：分心常是逃避不适  
一句话定义：无聊、焦虑和挫败可能先于分心行为出现。  
论证链：内部不适 → 寻找即时缓解 → 分心行为暂时减轻不适 → 习惯被强化  
证据：戒烟、心理治疗和作者案例；多数为A/D/E混合，不能直接证明所有分心都由不适引起。  
适用边界：寻找行为发生前的情绪线索。  
失效条件：纯粹由外部通知、同伴压力或平台奖励驱动时。  
与目标锚点的关系：直接可用。  
可操作化：学生分心后先记录情绪和任务难点，不用“自律差”解释；提供休息、求助和任务拆分。  
出处：[不可打扰·章3–5 / PDF p.33–70]

ID：BKDR-4-01  
类型：证据  
名称：无聊与自我刺激  
一句话定义：人在缺乏刺激时可能主动选择不利但即时的刺激。  
论证链：无事可做 → 寻找刺激 → 即时刺激压过长期目标 → 分心行为发生  
证据：2014年《科学》杂志研究；独处时67%男性、25%女性选择电击自己；样本规模和实验细节本书未涉及；实验性证据，等级未定。  
适用边界：说明单纯“删掉手机”不能消除所有分心。  
失效条件：把结果推广为儿童普遍行为或证明数字设备必然有害。  
与目标锚点的关系：需改造。  
可操作化：课程安排有意义的低刺激过渡活动和自主选择，不以无限内容填满空档。  
出处：[不可打扰·章4 / PDF p.539–546]

ID：BKDR-5-01  
类型：证据  
名称：压抑欲望可能反弹  
一句话定义：强迫自己“不去想”某事，反而可能提高其出现频率。  
论证链：压抑念头 → 监控是否想到 → 目标念头被持续激活 → 冲动增强  
证据：韦格纳“白熊”实验；样本规模和年份正文未涉及；实验性证据，等级未定。空乘人员戒烟研究亦提示延迟后冲动变化，细节未充分呈现。  
适用边界：冲动管理和自我观察。  
失效条件：高危内容需要立即阻断时，不能以“观察”替代安全措施。  
与目标锚点的关系：直接可用。  
可操作化：教孩子标记冲动、等待和选择替代行为；平台层仍需默认屏蔽高风险内容。  
出处：[不可打扰·章5–6 / PDF p.635–832]

ID：BKDR-6-01  
类型：方法工具  
名称：冲动冲浪与触因记录  
一句话定义：观察冲动的起伏，记录分心前的情绪和情境。  
论证链：识别触因 → 写下感受 → 带好奇心观察变化 → 冲动自行下降或转向有价值行动  
证据：布里克戒烟研究与ACT方法；作者称实验组吸烟量减少，但样本、效应量和具体设计书中未完整呈现；强度A/D。  
适用边界：可逆、低风险的分心冲动。  
失效条件：儿童处于严重焦虑、网络欺凌或成瘾戒断状态时需专业支持。  
与目标锚点的关系：直接可用。  
可操作化：设置“我现在感到什么—想做什么—先等几分钟”的卡片，不采集可识别的敏感心理数据。  
出处：[不可打扰·章6 / PDF p.737–832]

ID：BKDR-9-01  
类型：方法工具  
名称：时间盒  
一句话定义：把每天要做的事按时间预先安排，并用计划判断是否分心。  
论证链：价值澄清 → 具体时间块 → 按计划行动 → 复盘并调整下一周  
证据：作者称基于实施意图研究；具体研究、样本与效应本批未完整定位；强度未定。  
适用边界：可由个人调整的学习、休息和关系时间。  
失效条件：把日程排满、忽视恢复和突发需要，或用计划监控儿童而非支持其自主。  
与目标锚点的关系：直接可用。  
可操作化：为AI课设置创作、协作、休息、设备使用和离线活动时间；孩子参与制定并可修改。  
出处：[不可打扰·章9–12 / PDF p.71–100]

ID：BKDR-10-01  
类型：反直觉结论  
名称：控制投入而非结果  
一句话定义：专注于可控的时间和行动，结果不作为唯一自我评价。  
论证链：结果受外部因素影响 → 只盯结果增加焦虑 → 按计划投入可控时间 → 更稳定地接近目标  
证据：作者实践与休息研究的概括；具体证据待后续核查，强度D/E。  
适用边界：长期学习和创造性任务。  
失效条件：完全不检查结果或质量，导致低效重复。  
与目标锚点的关系：直接可用。  
可操作化：评价“投入时间、调试次数、解释质量、迁移任务”，而非在线时长。  
出处：[不可打扰·章10 / PDF p.79–91]

## 本批反向提醒

1. “分心源于不适”是有用假设，不是解释所有分心的充分因果理论。[推论]
2. 时间盒若被成人强制执行，可能变成新的控制与焦虑来源。[推论]
3. 对儿童讲“意志力用之不竭”不能替代平台级默认保护和专业帮助。[推论]
