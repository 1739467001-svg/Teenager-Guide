# 《上瘾》精读卡片：批次3

范围：PDF p.142–160，第7–8章。

ID：SY-7-01  
类型：案例  
名称：《圣经》应用的四阶段实现  
一句话定义：移动可达性、短片段、提醒、反馈和用户标注形成完整循环。  
论证链：随身设备降低行动成本 → 每日提醒触发 → 短片段与音频促成阅读 → 经文/完成标记提供酬赏 → 高亮、评论、书签和计划数据加载下一触发  
证据：YouVersion公司访谈与运营数据；2013年安装量超过1亿、每1.3秒一次新安装、每秒约66000人打开、18%用户在洗手间使用，均为公司/作者转述，样本定义与独立审计书中未涉及；强度 E。  
适用边界：说明如何把已有纸面活动转成低摩擦数字流程。  
失效条件：把宗教承诺、焦虑或连续打卡用于儿童留存；高频不等于理解。  
与目标锚点的关系：需改造。  
可操作化：AI课程可把项目拆成短任务并提供解释性反馈，但不得使用夜间推送、连续链条惩罚或情绪化提醒。  
出处：[上瘾·章7 / PDF p.142–150]

ID：SY-7-02  
类型：证据  
名称：内容顺序与音频降低行动摩擦  
一句话定义：前置易懂内容、短片段和音频可能提高开始率。  
论证链：任务负担下降 → 更容易开始 → 完成频率上升 → 形成重复行为  
证据：YouVersion团队称其数据筛选支持这些设计；数据集、对照组、效应量和研究年份书中未涉及；强度 E。  
适用边界：降低进入门槛，同时保留目标所需的认知挑战。  
失效条件：把内容切碎到无法形成整体理解，或只优化点击/完成率。  
与目标锚点的关系：直接可用。  
可操作化：为9–14岁学习者提供渐进任务、朗读/代码示例和可选辅助；另测概念理解、迁移和独立完成，而非只看完成率。  
出处：[上瘾·章7 / PDF p.145–150]

ID：SY-8-01  
类型：方法工具  
名称：习惯测试三步法  
一句话定义：确定习惯用户、分析共同路径、改进产品并复测。  
论证链：定义目标行为 → 找到高频用户及共同行为 → 调整入口/功能 → 比较调整前后结果  
证据：作者受精益创业“建造—评估—学习”启发的实践框架；5%习惯用户为作者经验基准，非普遍定律；样本与验证年份书中未涉及；强度 E。  
适用边界：发现产品使用路径和迭代假设。  
失效条件：把高频用户当作理想用户，或把留存提升直接视为儿童获益。  
与目标锚点的关系：直接可用，但必须加入安全和学习结果指标。  
可操作化：按年龄、课程基础和辅助需求分组；同时追踪理解、创造、休息、退出率和负面体验；任何留存实验须预设停止标准。  
出处：[上瘾·章8 / PDF p.151–154, 159–160]

ID：SY-8-02  
类型：方法工具  
名称：习惯路径分析  
一句话定义：从忠实用户共同经历的行为序列寻找关键节点。  
论证链：识别长期参与者 → 提取注册、关注、互动等共同序列 → 推动新用户尝试相关行为 → 评估是否改善体验  
证据：Twitter“关注30人”案例；样本、因果识别和具体时期书中未涉及；强度 D/E。  
适用边界：产品漏斗和学习流程诊断。  
失效条件：为了复制路径而强迫关注、公开社交或收集过量数据。  
与目标锚点的关系：需改造。  
可操作化：寻找“完成一次可迁移作品”的学习路径，不设社交人数阈值；只使用最小化、可撤回的行为数据。  
出处：[上瘾·章8 / PDF p.152–154]

ID：SY-8-03  
类型：争议点  
名称：自用产品寻找机会  
一句话定义：作者建议从设计者自身问题和行为中发现产品机会。  
论证链：亲身遇到问题 → 观察真实行为 → 找到摩擦 → 设计更简单方案  
证据：Buffer创始人案例；2010年创建、用户超过110万为作者转述，独立验证和样本书中未涉及；强度 E。  
适用边界：设计者与用户处境相近的探索阶段。  
失效条件：成人设计者把自身偏好投射到儿童，忽视发展阶段、残障和家庭差异。  
与目标锚点的关系：仅作背景，不能作为儿童需求证据。  
可操作化：设计者自用只能生成假设；必须由儿童、家长、老师的观察和可退出测试验证。  
出处：[上瘾·章8 / PDF p.154–158]

## 本批反向提醒

1. 案例中的高安装、高打开和高留存数据不能证明学习或福祉改善。[推论]
2. “5%习惯用户”和“关注30人”是经验案例，不是儿童教育通用阈值。[推论]
3. 数据驱动迭代若只优化留存，会把《上瘾》的商业目标重新带回教育产品。[推论]
