ID：SY-前言-01  
类型：框架模型  
名称：上瘾模型四阶段  
一句话定义：触发、行动、多变酬赏与投入组成循环。  
论证链：问题或情绪触发 → 用户低摩擦行动 → 获得不确定酬赏 → 投入数据/精力 → 下一轮触发更容易  
证据：作者对企业案例的归纳及顾问经验；观察对象称“上千家公司”，年份未形成统一研究设计；样本筛选和比较方法书中未涉及；强度 E。  
适用边界：用于检查产品是否系统性推动重复行为，不能单凭模型判断行为有益或有害。  
失效条件：低频任务、没有即时反馈的任务，或用户每次都必须审慎决策的高风险活动。  
与目标锚点的关系：直接可用，但必须作为风险审计框架，而不是留存增长处方。  
可操作化：对每个课堂/产品环节标出四阶段；凡形成无停止点循环者，必须增加透明提示、自然结束点和无惩罚退出。  
出处：[上瘾·前言 / PDF p.12–19]

ID：SY-1-01  
类型：概念  
名称：习惯与自动化行为  
一句话定义：习惯是在情境暗示下几乎不经思考的行为。  
论证链：重复情境与行为配对 → 行为被储存为自动反应 → 相同线索出现时减少主动决策  
证据：作者引用认知心理学定义和神经机制，并称近一半日常活动受习惯支配；具体研究名称、样本、年份正文未涉及；强度未定位。  
适用边界：稳定、重复、结果相对可预测的行为。  
失效条件：情境频繁变化、任务需要深度推理，或学习者尚未掌握基本技能。  
与目标锚点的关系：需改造。基础操作可自动化，核心思考不能被自动点击替代。  
可操作化：只把打开工具、保存作品、提交检查等程序性动作习惯化；创意选择和问题分解保留显性思考。  
出处：[上瘾·前言、章1 / PDF p.10, 20–21]

ID：SY-1-02  
类型：因果机制  
名称：高频接触强化习惯  
一句话定义：行为出现越频繁，形成稳定自动反应的可能性越高。  
论证链：频繁重复 → 情境与反应连接增强 → 选择时减少比较 → 行为成为默认选项  
证据：作者引用伦敦大学学院牙线习惯研究；研究年份正文未明确、样本规模书中未涉及、纵向观察设计，暂列 B；作者另提2010年研究显示形成期从数周到5个月以上，样本书中未涉及，暂列 B。  
适用边界：行为简单、线索稳定、用户能够反复实践。  
失效条件：只提高次数却没有可感知价值，或重复导致疲劳、抵触和机械应付。  
与目标锚点的关系：直接可用，但只适用于有学习价值的练习。  
可操作化：用短而分散的检索练习巩固关键技能；不得用无意义签到、连续登录天数制造虚假频率。  
出处：[上瘾·章1 / PDF p.27, 30–31]

ID：SY-1-03  
类型：框架模型  
名称：习惯区间  
一句话定义：频率与可感知用途共同决定行为能否成为习惯。  
论证链：行为频率提高 + 用户感知到价值 → 进入习惯区间 → 成为默认行为  
证据：作者提出的二维概念图；通用阈值、样本和验证年份书中明确表示不存在；属于理论/经验框架，强度 E。  
适用边界：用于提出产品假设，不适合当作精确预测模型。  
失效条件：把“频率高”直接等同于“学习效果好”，或忽视被迫使用。  
与目标锚点的关系：需改造。  
可操作化：同时测量参与频率与学习者认可的用途；只有两者都成立才考虑保留机制。  
出处：[上瘾·章1 / PDF p.29–31]

ID：SY-1-04  
类型：争议点  
名称：习惯价值与转换成本  
一句话定义：储存价值和熟练度会提高留存，也会抬高退出成本。  
论证链：用户投入内容/技能/关系 → 迁移损失增加 → 更少比较替代方案 → 原产品获得竞争优势  
证据：QWERTY、Gmail、Twitter、Instagram等案例；没有对照样本或统一年份；强度 E。  
适用边界：确实存在数据、技能或关系积累的服务。  
失效条件：留存来自锁定而非持续价值，特别是用户无法导出作品或数据时。  
与目标锚点的关系：直接可用作风险识别。  
可操作化：儿童作品、代码和学习记录必须可导出；更换平台不得造成学习成果清零或社交惩罚。  
出处：[上瘾·章1 / PDF p.25–26]

ID：SY-2-01  
类型：概念  
名称：外部触发四分类  
一句话定义：付费、回馈、人际和自主型提示从外部召唤行动。  
论证链：提示进入生活环境 → 明示或暗示下一步 → 用户行动 → 重复使用  
证据：营销与产品案例归纳；样本规模和统一年份书中未涉及；强度 E。  
适用边界：用户尚未形成内部触发，需要明确下一步时。  
失效条件：提示过多、选择过多，或提示与用户当下目标无关。  
与目标锚点的关系：直接可用。  
可操作化：课堂只保留服务学习目标的提示；通知默认关闭，由孩子和家长主动开启；禁止借同伴邀请制造压力。  
出处：[上瘾·章2 / PDF p.37–43]

ID：SY-2-02  
类型：因果机制  
名称：负面情绪成为内部触发  
一句话定义：无聊、孤独或不确定感可自动触发产品使用。  
论证链：出现轻微不适 → 使用产品获得即时缓解 → 情绪与产品反复配对 → 无外部提示也会使用  
证据：2011年密苏里科技大学追踪216名本科生一学年；网络行为与抑郁咨询行为相关，纵向观察 B；研究不证明网络使用缓解情绪，也不证明负面情绪单向导致使用。  
适用边界：成年或大学生样本中的关联；对9–14岁儿童不可直接平移。  
失效条件：产品没有真正缓解问题，反而只暂时回避或加重情绪。  
与目标锚点的关系：直接可用作禁用机制识别。  
可操作化：不得利用焦虑、掉队恐惧或孤独推动续课和登录；若孩子因挫败打开产品，应先提供求助、休息或真人支持。  
出处：[上瘾·章2 / PDF p.43–45]

ID：SY-2-03  
类型：方法工具  
名称：行为观察与五问法  
一句话定义：从真实行为连续追问原因，以寻找潜在需求。  
论证链：记录发生的行为 → 追问使用情境和感受 → 连续追问“为什么” → 形成可验证的内部触发假设  
证据：作者引用产品研究方法、用户情境和丰田“五问法”；样本、验证研究和年份书中未涉及；强度 E。  
适用边界：探索性研究和假设生成。  
失效条件：把访谈推测当作事实，或用诱导问题替儿童定义情绪。  
与目标锚点的关系：需改造。  
可操作化：访谈孩子、家长与老师并观察真实课堂；把“怕被抛弃”等深层原因标为待验证，不直接写入设计。  
出处：[上瘾·章2 / PDF p.45–47]

ID：SY-3-01  
类型：框架模型  
名称：福格行为模型 B=MAT  
一句话定义：行为需要动机、能力和触发在同一时刻出现。  
论证链：存在行动提示 + 有足够动机 + 行为处于能力范围内 → 跨过行动线 → 行为发生  
证据：福格博士提出的行为模型及产品案例；本书未给出该模型验证研究的样本、年份或效应量；强度未定位。  
适用边界：分析单次行为是否容易发生，不等于解释长期学习、理解或自主性。  
失效条件：用它预测复杂创造、持续努力或知识迁移。  
与目标锚点的关系：直接可用作行为诊断。  
可操作化：当学生未行动时，分别检查提示是否明确、任务是否过难、目标是否被学生认可，而不是笼统归因于“不自律”。  
出处：[上瘾·章3 / PDF p.50–52]

ID：SY-3-02  
类型：框架模型  
名称：六类能力障碍  
一句话定义：时间、金钱、体力、脑力、社会偏差和非常规性构成摩擦。  
论证链：某项资源稀缺或行为违背常规 → 完成成本上升 → 即使有动机也不行动  
证据：福格对简洁性的分类及产品案例；样本和验证年份书中未涉及；强度未定位。  
适用边界：识别行为摩擦，不代表所有摩擦都应该消除。  
失效条件：消除的是有助于思考、练习或反思的“必要难度”。  
与目标锚点的关系：直接可用。  
可操作化：每项作业检查六类障碍；降低登录、安装和提交摩擦，保留调试、推理和复盘所需的认知努力。  
出处：[上瘾·章3 / PDF p.56–59]

---

ID：SY-3-03  
类型：反直觉结论  
名称：先改善能力而非强化动机  
一句话定义：简化行动通常比继续说服用户更容易促成行为。  
论证链：动机昂贵且波动 → 降低非必要摩擦 → 用户更容易跨过行动线 → 行为概率上升  
证据：作者基于福格模型和Twitter、Google、iPhone、Pinterest案例的建议；无统一对照样本和年份；强度 E。  
适用边界：目标行为本身已被用户认可，且简化不损害目标。  
失效条件：行为目标由平台单方面设定，或简化导致自动滑动、无限消费和浅层完成。  
与目标锚点的关系：直接可用，但必须区分必要难度。  
可操作化：减少工具配置和界面负担；禁止用自动连播、无限滚动替学生取消自然停止点。  
出处：[上瘾·章3 / PDF p.67–73]

ID：SY-3-04  
类型：证据  
名称：稀缺效应实验  
一句话定义：相同物品会因数量较少而被评价得更有价值。  
论证链：呈现数量差异 → 稀缺成为判断线索 → 主观价值提高；数量由少变多时价值反而下降  
证据：1979年沃切尔、李、阿德沃勒等人的饼干罐实验；样本规模、随机分配和效应量书中未涉及；实验性证据但无法确认A等级，暂记“未定”。  
适用边界：短期主观价值判断。  
失效条件：推断稀缺能够改善长期学习质量，或把人为限量包装成真实资源不足。  
与目标锚点的关系：直接相关，原则上禁用。  
可操作化：不使用“仅剩名额”“限时领取奖励”等方式迫使儿童行动；真实期限须解释原因并提供补救。  
出处：[上瘾·章3 / PDF p.74–75]

ID：SY-3-05  
类型：证据  
名称：目标渐近效应  
一句话定义：感觉已接近目标会提高继续完成任务的概率。  
论证链：赠送虚拟起始进度 → 感知距离缩短 → 继续消费动机增强 → 完成比例提高  
证据：洗车穿孔卡现场实验；两组均需实际消费8次，预置两孔组完成者比空卡组高82%；研究年份、样本规模和随机化方法书中未涉及；实验性证据但等级未定。  
适用边界：目标明确、路径有限且终点真实的任务。  
失效条件：进度条与掌握程度无关、终点不断后移，或为了维持连续记录而惩罚中断。  
与目标锚点的关系：需改造。  
可操作化：进度只表示已掌握的明确技能，并允许暂停和恢复；不得用虚假初始进度或连续签到代替学习证据。  
出处：[上瘾·章3 / PDF p.76–77]

## 本批反向提醒

1. 高频和留存是商业价值指标，不是学习效果指标。[推论｜对应 SY-1-02、SY-1-03]
2. 降低摩擦既能帮助孩子开始学习，也能取消自然停止点；两者必须分开审查。[推论｜对应 SY-3-02、SY-3-03]
3. 与情绪建立内部触发可能让产品“有效”，但利用未成年人的焦虑、孤独或害怕掉队推动使用，不符合目标锚点。[推论｜对应 SY-2-02]
4. 《上瘾》前三章的证据多为成人案例、大学生研究和产品观察，儿童适用性整体未证实。[推论｜本批覆盖]
