# _归档 · 历史版本

> **这个目录里的文件，一律不作为写作参考来源。**

放在这里的原因，不是它们写错了，而是它们已经被更后面的版本取代，
或者当初是按另一套思路写的（招生口径、书稿口径），继续参考会把现在的材料带偏。

保留而不删除，只有两个用途：
1. 需要回溯「某个决定当初是怎么想的」时能查；
2. 需要对照「改了什么、为什么改」时能查。

| 文件 | 是什么 | 被谁取代 |
|---|---|---|
| `上瘾自律_AI创造营_完整课程_v1.md` | 四环节第一版修订 | `../上瘾自律_两天AI创造营_v3.md` |
| `上瘾自律_AI创造营_完整课程_v2.md` | 整合四个升级环节的第二版 | 同上 |
| `上瘾自律两天AI创造营_修订版.docx` | 原始课纲 + 首版修订 | 原始课纲部分仍是实战骨架的**唯一**引用源，修订部分已被 v3 取代 |
| `上瘾自律AI创造营_家长商业推广方案.md` | 早期招生文案 | 无（招生口径需要时重写，不在这版基础上改） |

## 一个例外，注意

`../把注意力拿回来_AI时代的上瘾自律与创造力.md`（8 章青少年书稿）**同样不作为参考来源**，
但它**没有**移进这里，因为下面两个在用的文件按路径引用了它：

- `知识库/设计红线与白名单.md`
- `教具/教具3_Hooked与Anti-hooked授课包.md`
