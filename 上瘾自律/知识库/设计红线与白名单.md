# 设计红线与白名单

> 这份文件是**可执行的**，不是价值观宣言。
> 用途：① 学员做产品时对照 ② 讲师巡场时判定 ③ 路演评分 ④ 家长沟通时解释「我们不做什么」

---

# 一、四条红线（对学员讲的版本）

课程里所有场合只讲这四条，一个字不改，反复出现：

| # | 红线 | 长什么样 |
|---|---|---|
| ① | **随机奖励** | 抽卡、随机掉落、盲盒、「差一点就成功」 |
| ② | **公开排名** | 排行榜、公开点赞数、谁比谁强、「你排第 N」 |
| ③ | **归零惩罚** | 连续记录断了清零、没完成扣资格、扣钱 |
| ④ | **焦虑逼迫** | 倒计时、限时、稀缺、「你的朋友都完成了」 |

**为什么只有四条？** 因为学员要在两天里记住并用出来。
更完整的判定标准在弹性尺（教具 4）的 A 层 6 题 + B 层 15 题。

# 二、完整禁用清单（讲师和产品评审用）

## 2.1 反馈与奖励

| 禁用 | 依据 |
|---|---|
| 抽奖、随机徽章、随机积分、盲盒、稀有度 | SY-4-02 间隔性强化；YBN-03-01 |
| 「差一点就成功」的近失体验 | YBN-03-01 |
| 与真实能力无关的进度条 | SY-3-05 目标渐近效应的失效条件 |
| 虚假初始进度（先送你两格） | SY-3-05 |
| 无限升级、无上限等级 | YBN-07-01 |
| 连续签到天数作为核心指标 | SY-1-02 可操作化条款 |

## 2.2 社交

| 禁用 | 依据 |
|---|---|
| 公开排行榜、热度排序、外貌评比 | JLD-6-02；YBN-09-01 |
| 公开点赞数、公开完成率 | JLD-6-01 |
| 强制组队、掉队惩罚 | YBN-09-01 |
| 借同伴邀请制造压力（「你的朋友都在用」） | SY-2-01 可操作化条款 |
| 匿名围攻、公开点名未完成者 | JLD-6-02 |

## 2.3 惩罚与承诺

| 禁用 | 依据 |
|---|---|
| 金钱押金、罚款 | BKDR-24-01（成人自愿戒烟研究不可迁移儿童） |
| 扣课程资格、锁功能 | BKDR-24-01 |
| 公开羞辱、「你辜负了自己」类文案 | BKDR-25-01 |
| 强制锁机、无法解除的限制 | BKDR-23-01 失效条件 |
| 阻断求助通道的任何设计 | BKDR-22-01；`阶段五` 第 4 条 |
| 成人替儿童签订的不可退出协议 | BKDR-22-01 |

## 2.4 时间与睡眠

| 禁用 | 依据 |
|---|---|
| 夜间推送 | JLD-5-02（ABCD 研究：睡眠干扰可预测一年后抑郁与行为问题） |
| 睡前任务安排 | JLD-5-02 |
| 无限滚动、自动连播 | SY-3-03 可操作化条款 |
| 没有自然停止点的任何流程 | SY-前言-01 可操作化条款 |
| 用未完成张力、倒计时逼迫回流 | YBN-08-01 |

## 2.5 数据与隐私

| 禁用 | 依据 |
|---|---|
| 收集用不上的个人信息 | SY-5-03；JLD-10-01 |
| 采集可识别的敏感心理数据 | BKDR-6-01 可操作化条款 |
| 用情绪数据做留存优化 | JLD-1-02 |
| 作品/数据不可导出 | SY-1-04（转换成本 → 锁定） |
| 把「疑似成瘾」等推断标签公开给同伴 | `把注意力拿回来` 第六章 |
| 以绑定通讯录/日历/社交账号作为使用前提 | SY-5-03, SY-5-04 |
| 全天候监控（区别于「家长可见关键设置」） | BKDR-32-01 |

# 三、白名单：允许且推荐的做法

| 做什么 | 为什么可以 | 依据 |
|---|---|---|
| **透明、可预测的反馈**：做什么得什么，事先写清楚 | 学习需要可预测、可解释、公平的反馈 | SY-4-02 边界；YBN-05-01 |
| **与能力变化挂钩的反馈**：上月 20kg → 本月 25kg | 奖励映射到具体技能，不是停留时长 | SY-4-04 可操作化 |
| **可关闭的徽章**，关了不影响核心功能 | 游戏层可关闭且不影响资格 | YBN-12-01；`阶段五` 第 3 条 |
| **明确终点**：每次使用到点会说「今天到这儿」 | 每个任务有清晰终点 | YBN-07-01；`阶段五` 第 3 条 |
| **可预设的休息日**，用了不掉级不催 | 弹性与自我同情，拒绝全或无 | BKDR-25-01；YBN-11-01 |
| **进度可保存、可重置、可补做** | 注意力失败必须可恢复 | `阶段五` 第 5 条 |
| **一键导出作品和记录** | 儿童作品/代码/学习记录必须可导出 | SY-1-04 可操作化 |
| **努力协议**：多加一步，而不是锁死 | 增加摩擦获得反思间隔 | BKDR-23-01 |
| **共同制定的时间盒**，孩子参与、可修改 | 自主参与优于成人强制 | BKDR-31-01 |
| **「我正在练习……」**式的身份表述 | 允许今天没做到，不做失败标签 | BKDR-25-01 |
| **小组合作**代替个人排名 | 保留归属，去掉比较 | `阶段四` 社交机制行 |
| **核心动作发生在屏幕外**，App 只记录和反馈 | 给线下活动留时间 | BKDR-35-01；JLD-11-01 |
| **默认夜间静默**，到点主动提示该睡了 | 睡眠优先 | JLD-5-02 |
| **通知默认关闭**，由孩子和家长主动开启 | 通知只在用户选择的时间窗口 | SY-2-01；BKDR-13-01 |
| **家长可见关键设置**，但不读取全部私密内容 | 家长可见 ≠ 全天候监控 | JLD-10-01；BKDR-32-01 |

# 四、判定流程（巡场用）

```
看到一个功能
   ↓
① 它属于四条红线里的任何一条吗？ ── 是 ──→ 🔴 当场改，不讨论
   ↓ 否
② 它给的反馈，用户能事先知道会得到什么吗？ ── 否 ──→ 🟠 让学员解释一遍，多半是伪装的随机
   ↓ 是
③ 用户不用它、少用它、今天不用它，会损失什么？ ── 有实质损失 ──→ 🟠 改成可恢复
   ↓ 无
④ 它的核心动作发生在屏幕里还是屏幕外？ ── 屏幕里 ──→ 🟡 问一句：能不能挪到屏幕外？
   ↓
✅ 通过
```

# 五、一句话判据（贴在墙上）

> ## 一个好的自律工具，不是让你离不开它。
> ## 是让你越来越有能力离开它，回到你自己的生活里。

如果一个功能让用户**更难离开**，它就站在这句话的反面——不管它有多好玩。
