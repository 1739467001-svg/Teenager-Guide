# 《上瘾自律》知识库

> 目标锚点：**为 9–14 岁青少年建立一套注意力设计的攻防标准**，并把它变成一门可以真的开起来的课。

---

## 三层结构

```
notes/          ← 第 1 层：原始素材。书里说了什么。只记录，不判断。
知识库/          ← 第 2 层：我们的判断。这些素材合起来意味着什么。
教具/ + 课程/课件 ← 第 3 层：落地物。判断怎么变成现场能用的东西。
实战记录/         ← 第 4 层：真的发生了什么。现场把设计打回来的那部分。
_归档/           ← 已被取代的版本。查得到，但不作为参考来源。
```

**单向引用规则**：第 3 层不直接引用书，只引用第 1 层的卡片编号（如 `SY-4-02`）。
这样任何一条设计决定，都能一路追溯回某一页 PDF。改了上层，下层能查出来哪里要跟着改。

**第 4 层为什么单独立一层**：前三层是推演出来的，第 4 层是撞出来的。
2026-09-05/06 首场试课之后我们才知道，桌游没印出来、Day2 被压成 1.5 小时——
这类信息推演不出来，只能记。**当第 4 层和第 3 层冲突时，以第 4 层为准。**

## 三条方法论纪律

写进任何一份材料之前先过一遍：

1. **成人案例、动物实验和横断面关联，不得直接升级为儿童因果结论。**
2. **研究的样本、效应量或随机化细节缺失时，原样写「书中未涉及」，不补写。**
   ——这是这个知识库和普通读书笔记的根本区别，也是 AI 最容易破功的地方。
3. **涉及未成年人的机制先过伦理闸门**：默认关闭、家长可见、可退出无惩罚、保留求助与无障碍通道。

| # | 红线 | 长什么样 |
|---|---|---|
| ① | 随机奖励 | 抽卡、随机掉落、「差一点就成功」 |

## 怎么继续往里加东西

| 加什么 | 放哪 |
|---|---|
| 读了新书 / 新章节 | `notes/` 新建批次文件，沿用卡片格式；更新 `../progress.md` |
| 想通了一个概念 | `知识库/核心概念词典.md` 加词条，**必须填「它不能解释什么」** |
| 发现一个该禁/该推荐的设计 | `知识库/设计红线与白名单.md` 对应表加行，附卡片编号 |
| 和 Claude 讨论出了新理解 | `知识库/理解沉淀_对话层.md` **追加**一条，不覆盖旧的 |
| 课程改了 | 主课程文件升版本号，旧版**移进 `_归档/`** 并在 `_归档/README.md` 记一行「被谁取代」 |
| 又上了一次课 | `实战记录/` 新建 `YYYY-MM-DD_场次名.md`，只记发生了什么，不确定的标「待确认」 |
| 课件改了 | 改 `课件/源码/` 里的脚本重新生成，**不要直接改 pptx**；改完跑一遍 `qa.py` |

## 现在走到哪了

**2026-09-05 / 06，这门课第一次真的开了。** 深圳福田，4 个孩子，两天，四个家庭共 550 元自愿打赏。
主讲是 14 岁的超级富，我（陈俊烨）没到场，全程远程兜底。

这件事把这个仓库的性质改了一半：在此之前所有材料都是推演出来的，现在有一份是撞出来的。
现场记录见 `实战记录/2026-09-05_06_首场试课.md`，其中四件 v4 必须改的事：

1. **核心 40% / 可砍 60%** —— 现场只要一压缩就得当场砍，砍的顺序必须预先写死，不能临时决定。
2. **每个环节都要有零材料备份方案** —— 桌游没印出来就直接没跑，这种失败不该由「材料到没到」决定。
3. **报名环节要有筛选题** —— 4 个孩子的能力和状态跨度，超过了同一套任务能覆盖的范围。
4. **路演硬计时 3+2 分钟** —— 每组 20 分钟等于没有路演。

**下一批优先级**（详见 `知识库/理解沉淀_对话层.md` 末尾）：
① 按实战记录出 v4（含核心/可砍清单 + 零材料备份）②用弹性尺给课程本身打分
③《上瘾式学习》分块精读 ④抽一份神经多样性学员适配指南
