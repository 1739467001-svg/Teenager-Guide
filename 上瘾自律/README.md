# 《上瘾自律》知识库

> 目标锚点：**为 9–14 岁青少年建立一套注意力设计的攻防标准**，并把它变成一门可以真的开起来的课。

---

## 三层结构

```
notes/        ← 第 1 层：原始素材。书里说了什么。只记录，不判断。
知识库/        ← 第 2 层：我们的判断。这些素材合起来意味着什么。
教具/ + 课程    ← 第 3 层：落地物。判断怎么变成现场能用的东西。
```

**单向引用规则**：第 3 层不直接引用书，只引用第 1 层的卡片编号（如 `SY-4-02`）。
这样任何一条设计决定，都能一路追溯回某一页 PDF。改了上层，下层能查出来哪里要跟着改。

## 三条方法论纪律

写进任何一份材料之前先过一遍：

1. **成人案例、动物实验和横断面关联，不得直接升级为儿童因果结论。**
2. **研究的样本、效应量或随机化细节缺失时，原样写「书中未涉及」，不补写。**
   ——这是这个知识库和普通读书笔记的根本区别，也是 AI 最容易破功的地方。
3. **涉及未成年人的机制先过伦理闸门**：默认关闭、家长可见、可退出无惩罚、保留求助与无障碍通道。

## 四条红线（贯穿全课程）

| # | 红线 | 长什么样 |
|---|---|---|
| ① | 随机奖励 | 抽卡、随机掉落、「差一点就成功」 |
| ② | 公开排名 | 排行榜、点赞竞争、谁比谁强 |
| ③ | 归零惩罚 | 连续记录清零、没完成扣资格、扣钱 |
| ④ | 焦虑逼迫 | 倒计时、限时、稀缺、「你的朋友都在用」 |

## 怎么继续往里加东西

| 加什么 | 放哪 |
|---|---|
| 读了新书 / 新章节 | `notes/` 新建批次文件，沿用卡片格式；更新 `../progress.md` |
| 想通了一个概念 | `知识库/核心概念词典.md` 加词条，**必须填「它不能解释什么」** |
| 发现一个该禁/该推荐的设计 | `知识库/设计红线与白名单.md` 对应表加行，附卡片编号 |
| 和 Claude 讨论出了新理解 | `知识库/理解沉淀_对话层.md` **追加**一条，不覆盖旧的 |
| 课程改了 | 主课程文件升版本号，旧版保留 |
| 试课后的现场记录 | `教具/` 对应文件末尾加「实战记录」小节 |
