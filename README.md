# Teenager-Guide

给青少年的注意力与创造力知识库。

## 目前的内容

### [`上瘾自律/`](上瘾自律/) — 上瘾机制的攻防研究与两天 AI 创造营

从《上瘾》《焦虑的一代》《不可打扰》《欲罢不能》四本书的分块精读出发，
建立一套面向 9–14 岁的**注意力设计攻防标准**，并落地成一门两天的 AI 创造营课程。

- **96 张精读卡片**，每张标注证据强度、适用边界、失效条件、PDF 页码
- **四份可直接执行的教具**：上瘾桌游、坏习惯挑战说明书、50 分钟授课逐字稿、弹性测评量表
- **一整套课件**：45 页主课件 + 17 页弹性尺专题 + 主视觉海报，全部由脚本生成
- **一份持续生长的理解沉淀**
- **一份真实试课的现场记录** —— 2026-09-05/06 这门课第一次真的开了

👉 从 [`上瘾自律/README.md`](上瘾自律/README.md) 进入

## 这个仓库怎么读

```
上瘾自律/
├─ notes/       第 1 层 · 书里说了什么      只记录，不判断
├─ 知识库/       第 2 层 · 我们判断什么      含分歧与未解决项
├─ 教具/ 课件/   第 3 层 · 我们做了什么      现场能直接用的东西
├─ 实战记录/     第 4 层 · 真的发生了什么    与第 3 层冲突时以它为准
└─ _归档/        已被取代的版本，不作为参考来源
```

两条贯穿全仓库的纪律：

1. **单向引用**：第 3 层不直接引用书，只引用第 1 层的卡片编号，任何一条设计决定都能追回某一页 PDF。
2. **不补写**：书里没交代样本、效应量、随机化的，原样写「书中未涉及」；现场记不清的，原样写「待确认」。
